THE WORKFLOW

From Market Data to Executed Trade

Every trading day, the system runs a fully automated pipeline — no human input required at any stage.

01
Ticker Selection — Capitol Trades Intelligence
Each morning, the system scrapes the legally-required trade disclosures filed by US Congress members. It scores politicians by historical performance and recency, then selects the tickers they've been buying. These are the stocks that go into the analysis pipeline.
Quiver Quantitative API Capitol Trades Politician scoring 8:00 AM daily
02
Layer 1 — Four Analyst Reports Generated in Parallel
For each selected ticker, four specialist AI agents produce independent research reports simultaneously. The Market Analyst runs technical indicators (MACD, RSI, Bollinger Bands). The Fundamentals Analyst evaluates earnings, free cash flow, and valuation. The News Analyst scans global news and macro events. The Sentiment Analyst reads social media, Reddit, and institutional mood.
Market Analyst Fundamentals Analyst News Analyst Sentiment Analyst LangGraph streaming
03
Layer 2 — Bull vs Bear Debate, Research Manager Judges
A Bull Researcher and a Bear Researcher each read all four analyst reports and construct the strongest possible argument for their side. They debate multiple rounds. The Research Manager then acts as judge — weighing both arguments and issuing a formal Investment Plan with a recommended action and position size.
Bull Researcher Bear Researcher Research Manager Multi-round debate
04
Layer 3 — Trader Proposes, Risk Team Debates
The Trader agent synthesises the Investment Plan into a concrete trade proposal: entry price, position size, price target, and stop-loss level. Three Risk Analysts then debate the proposal from different angles — Aggressive (maximise return), Conservative (protect capital), and Neutral (balanced view).
Trader Aggressive Risk Analyst Conservative Risk Analyst Neutral Risk Analyst
05
Layer 4 — Portfolio Manager Issues Final Decision
The Portfolio Manager reads everything — all four analyst reports, the debate, the investment plan, the trade proposal, and all three risk assessments — and issues a structured final decision with a 5-tier rating: Buy, Overweight, Hold, Underweight, or Sell. This decision is saved to the database and displayed in the Agent Log.
Portfolio Manager Buy / Overweight / Hold / Underweight / Sell Structured output
06
Execution — Alpaca Order Placed Automatically
The Alpaca Execution Bridge maps the Portfolio Manager's rating to an order. Buy and Overweight ratings trigger a market buy order sized according to the position sizing recommendation. Hold means no action. Underweight reduces an existing position. Sell closes it entirely. All orders are logged with their order ID.
Alpaca API Paper trading supported Order logging 9:00 AM Mon–Fri
07
Protection — Trailing Stop Monitor Runs Every 5 Minutes
A separate Celery task runs every 5 minutes during market hours. It checks every open position and ratchets the stop-loss floor upward whenever the price rises — locking in profits automatically. If the price drops to the stop floor, Alpaca executes the sell. The floor only ever moves up, never down.
Trailing stop Every 5 minutes Persistent state Celery Beat
08
Income — The Wheel Strategy Generates Premium
For tickers rated Buy or Overweight, the Wheel Strategy activates. Stage 1: sell a cash-secured put at the stop-loss strike — collecting premium while waiting to buy. If assigned, Stage 2: sell a covered call at the price target strike — collecting premium while waiting to sell. The cycle repeats, generating income on every position.
Cash-secured puts Covered calls Premium collection Options
CAPABILITIES

Everything in One System

Six core capabilities that work together to create a fully autonomous trading operation.

Capitol Trades Intelligence
Automatically tracks and scores trade disclosures by US Congress members. Filters to high-performing politicians (Pelosi, McCaul, Gottheimer) and uses their buys as the input ticker list for the AI analysis pipeline. Historically outperforms the S&P 500 by 10-20%.
11-Agent AI Analysis
The full TradingAgents multi-agent framework runs on every ticker. Four analysts, two debaters, a research manager, a trader, three risk analysts, and a portfolio manager — all powered by your choice of LLM (GPT-5, Claude 4, Gemini 3, Grok, DeepSeek, or local Ollama).
Wheel Strategy Automation
Fully automated options income strategy. The system uses TradingAgents' own price targets and stop-loss levels as the call and put strikes — so the AI analysis directly informs the options strategy. Tracks premium collected, DTE countdown, and cycle P&L per ticker.
Trailing Stop Protection
Every open position is monitored every 5 minutes. As the price rises, the stop-loss floor rises with it — locking in profits automatically. The floor never moves down. State is persisted across restarts so no position is ever left unprotected.
Agent Room — Live View
Watch all 11 agents work in real-time. Each agent card activates with a live indicator, shows a thinking animation, then reveals its full report as the LangGraph pipeline streams results. The final Portfolio Manager decision animates in with a colour-coded rating badge.
Celery Beat Scheduling
All tasks are managed by Celery Beat with schedules stored in PostgreSQL — editable from the Django admin without any code changes. The daily analysis, trailing stop monitor, wheel cycle, position sync, and Capitol Trades fetch all run automatically on their own schedules.

SETUP GUIDE

Up and Running in 3 Steps

The entire system deploys with a single Docker Compose command. Start with paper trading to validate the pipeline before going live.

01
Configure Your Credentials
Copy the example environment file and fill in your API keys. You'll need an Alpaca account (free, paper trading available), a Quiver Quantitative API key (free tier), and an OpenAI or other LLM provider key.
cp .env.example .env
# Edit .env with your keys
02
Start the Full Stack
Docker Compose starts the Django web server, Celery worker, Celery Beat scheduler, PostgreSQL database, and Redis broker. The entrypoint script runs migrations and configures all schedules automatically on first boot.
docker compose up -d
03
Open the Dashboard
Navigate to the dashboard, open the Agent Room, type a ticker, and hit Run Agents to watch the full pipeline execute. Check the Agent Log for the decision, then switch Alpaca from paper to live when you're confident in the results.
http://localhost:8080
